# Use case 2 run outputs, 22 to 23 July 2026

Raw outputs from the pre/post inference use case, and the only copy: they were
generated on the benchmark host into a gitignored `results/` directory and
existed nowhere else until they were moved here.

Kept because they are what produced `usecase-2-inference/pre-post-report.html`,
the report that has circulated. Superseded once that use case is re-run.

Five engine variants plus a control: no control, an RE2 guard, a simulated
inline path, and the two live engines. `run_all.csv` is the summary.

Not measured under any of the discipline applied later in the week. No manifest,
no recorded rig, no driver headroom. Do not quote figures from these without
re-measuring.
